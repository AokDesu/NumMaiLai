NumMaiLai น้ำไม่ไหล (MWA Notifier)

ระบบตรวจจับและแจ้งเตือนเหตุน้ำประปาไม่ไหล / ซ่อมบำรุงท่อ การประปานครหลวง

0 เหตุการณ์ทั้งหมด 0 ตรงกับพื้นที่ของคุณ
ท่อแตกรั่ว (ฉุกเฉิน) ปิดประตูน้ำ ตัดบรรจบ บำรุงรักษา/Step Test พิกัดบ้านของคุณ
💡 คำแนะนำ: สามารถคลิกบนแผนที่เพื่อย้ายพิกัดบ้านของคุณ หรือลากหมุดสีน้ำเงินเพื่อปรับตำแหน่ง

📍 โหมดการกรองพื้นที่ (Matching Mode)

📍 1. พิกัดและรัศมี (GPS Location & Radius)

🔑 2. คำค้นหาพื้นที่/ถนน/ซอย (Keywords)

กรอกชื่อถนน, ซอย, ตำบล หรือชื่อหมู่บ้าน (กด Enter หรือใส่เครื่องหมายจุลภาคเพื่อเพิ่มคำ)

🏢 3. สาขาการประปานครหลวง (MWA Branches)

เลือกสาขาที่ต้องการรับการแจ้งเตือน (ปล่อยว่างเพื่อรับทุกสาขา)

💬 การตั้งค่า Discord Webhook

สร้าง Webhook ได้ใน Server Settings > Integrations > Webhooks บน Discord
